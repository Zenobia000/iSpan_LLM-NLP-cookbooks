# M4 知識收斂 — 投影片生成提示詞

> 視覺風格：深色系精緻簡報 × 插圖手繪混搭 ｜ 比例 16:9 ｜ 模組主色：霧霾鴨綠 muted teal #5E948C（收斂層主色，低飽和、無霓虹） ｜ 工具：gpt-image-2（draw skill）
> 文字：標題/內文皆為乾淨平整向量級無襯線字、字寬自然不壓縮；手繪感只用於插圖與標註。
> 用法：逐頁複製「生圖提示詞」餵入生圖（建議 `--size 1536x1024 --quality medium` 以求中文清晰）；每頁文字精簡，中文為主、術語保留英文。
> 所屬：收斂層

## 全模組共用設計系統 token
（此處分兩組精煉條列，供逐頁共用，每頁提示詞已內含、此處方便檢視）

**視覺/配色（6 條）**：
- 底色深炭灰到墨黑平滑細微漸層（#101010 → #1E1E1E），可疊極淡幾乎不可見紋理，保持平整專業、非黑板。
- 主體為「暗底＋粉筆白 #ECE8E0」，副文字暖灰 #9A958C；視覺重心永遠是粉筆白。
- 模組主色 muted teal #5E948C 僅作節制點綴（重點圈選、關鍵詞、引線、節點高亮）。
- 手繪層（粉筆/蠟筆/低飽和 marker 質感）只用於箭頭、圈選、波浪底線、隨手框、便利貼、★、↗，線條刻意不工整、霧面不發光。
- 嚴禁霓虹、螢光、發光 glow、電光 cyber 色、俗氣 3D、stock photo、彩虹漸層、浮水印。
- 大量留白、清晰視覺層級、單頁聚焦一觀念、對齊乾淨。

**版面/字體/字級（6 條）**：
- 16:9，四周安全邊距 7-9%、內容不貼邊、左對齊基線網格、統一間距。
- 上下各保留一條乾淨空白帶供後製：不畫模組編號徽章、不畫課程名、不畫層別標、不畫頁碼。
- 兩帶結構：標題帶（小型 kicker eyebrow＋主色小圓點，其下 H1 左對齊）＋主視覺帶（最大區塊、垂直置中於安全區）。
- 字體：中文思源黑體 / Noto Sans TC（標題 Bold、內文 Regular），渲染為乾淨平整銳利向量級字、字寬自然不壓縮不擠窄、字距均勻；英數術語 Inter；等寬 JetBrains Mono；手寫感只用於插圖標註。
- 字級階層：封面 Display 特大（畫面高約 1/6–1/5）；內頁 H1 約 Display 60%、大而醒目；kicker 小、字距略寬；body 中等、行距約 1.5；caption 小。標題與內文至少差 2–2.5 倍。
- 每頁固定四槽：①kicker 段落歸屬 ②H1 頁標題 ③主視覺/圖解 ④手繪標註層；密度 ≤ 約 5 個元素群組、寧缺勿擠。
