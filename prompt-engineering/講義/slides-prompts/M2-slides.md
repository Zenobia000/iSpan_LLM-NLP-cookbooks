# M2 意圖收斂與上下文工程 — 投影片生成提示詞

> 視覺風格：深色系精緻簡報 × 插圖手繪混搭 ｜ 比例 16:9 ｜ 模組主色：霧霾鴨綠 muted teal #5E948C 為主、暖珊瑚 muted coral #C9756A 為重點章副強調（皆低飽和、無霓虹） ｜ 工具：gpt-image-2（draw skill）
> 文字：標題/內文皆為乾淨平整向量級無襯線字、字寬自然不壓縮；手繪感只用於插圖與標註。
> 用法：逐頁複製「生圖提示詞」餵入生圖（建議 `--size 1536x1024 --quality medium` 以求中文清晰）；每頁文字精簡，中文為主、術語保留英文。
> 所屬：收斂層 ・ 課程重點章 ★

## 全模組共用設計系統 token
（此處分兩組精煉條列，供逐頁共用，每頁提示詞已內含、此處方便檢視）

**視覺/配色（6 條）**：
- 底色深炭灰到墨黑平滑細微漸層 #101010 → #1E1E1E，疊極淡幾乎不可見的紋理，保持平整專業的簡報質感（非厚重黑板）。
- 暗底＋粉筆白 #ECE8E0 為絕對主體；副文字暖灰 #9A958C；主色 muted teal #5E948C 作重點圈選/關鍵詞/引線的節制點綴，重點章副強調用 muted coral #C9756A。
- 手繪只用於插圖與標註層：粉筆/蠟筆/低飽和 marker 質感的箭頭、圈選、波浪底線、隨手框、便利貼、★星號、↗ 引線；線條刻意不工整、霧面不發光。標題與內文一律乾淨向量、不可手寫化。
- 一律低飽和、霧面色調；嚴禁霓虹、螢光、發光 glow、光暈、高彩度電光色。
- 禁止標題被壓縮或手寫化、俗氣 3D、stock photo 人像、彩虹漸層濫用、雜亂堆砌、浮水印。
- 中文為主、技術名詞保留英文原文；圖上中文務必精簡，長段落以文字塊/條列線示意。

**版面/字體/字級（6 條）**：
- 16:9，四周安全邊距 7–9%、內容不貼邊、不侵入四角；整體左對齊基線網格、統一間距與呼吸感。
- 不畫任何頁首列與頁尾列：不畫模組編號徽章、不畫課程名、不畫層別標、不畫頁碼；畫面上方與下方各保留一條乾淨空白帶供後製。
- 兩帶結構：標題帶（upper）放小型 kicker/eyebrow 段落歸屬（加 teal 小圓點）＋ H1 頁標題，皆左對齊；主視覺帶（center）為最大區塊、垂直置中於安全區。
- 字體：中文思源黑體/Noto Sans TC（標題 Bold、內文 Regular，渲染為乾淨平整銳利向量字、字寬自然不壓縮不擠窄、字距均勻像真實簡報軟體）；英數術語 Inter；程式碼 JetBrains Mono；僅插圖手繪標註用 marker/chalk 手寫感字。
- 字級階層：封面 Display 特大（畫面高約 1/6–1/5）；內頁 H1 約 Display 60%；kicker 小、字距略寬；body 中等、行距約 1.5；caption 小。標題與內文至少差 2–2.5 倍、左對齊。
- 單頁聚焦一觀念，主視覺元素群組 ≤ 5，寧缺勿擠；對齊乾淨、留白充足。
