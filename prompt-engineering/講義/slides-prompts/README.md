# 課程「AI 交互工程與系統設計（2026）」投影片生圖提示詞集

> M0–M9 · Grok 暗黑 × 手繪風 · gpt-image-2

這是逐頁投影片生圖提示詞集。每一份檔案對應一個模組，內含該模組逐頁的生圖提示詞——逐頁複製貼上餵給 **gpt-image-2** 即可生成整套課程投影片。

全套統一風格為「**深色系精緻簡報（Keynote／PowerPoint 質感）× 插圖手繪混搭**」：16:9 版面、暗底＋粉筆白為主色，低飽和度的分層主色節制點綴——思維層用暖陶土橙、收斂層用霧霾鴨綠，重點章用暖珊瑚、規模化層用鼠尾草綠。一律**無霓虹、無發光**。標題與內文皆採乾淨平整的向量級無襯線字、字寬自然不壓縮，手繪感**只**用於插圖。

建議生圖參數：`--size 1536x1024 --quality medium`，以求中文清晰。模組編號／課程名／層別／頁碼**皆不畫**，由使用者後製外加。
