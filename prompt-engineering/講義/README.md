## 全課主軸

**把「下一步由誰決定」的控制權，從模型逐格收回系統。** 每一章開場都先回答「這一層要收回什麼控制權」，每一章驗收都落到「換人照做也成立」的可檢驗標準。

核心心法：**你可以外包你的思考，但不能外包你的理解。**

## 建議授課順序

M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7 → M8 → M9（即檔名順序）。
M2 是地基（spec 契約是後續所有層的共同起點），M7 是靈魂（評估驅動貫穿全課），建議多分配時數。
