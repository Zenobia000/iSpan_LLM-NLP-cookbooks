## 一、兩套教材的關係：理論母本 → 工程重構

| | ihower workshop v25 | 現有 prompt-engineering（本課） |
| :--- | :--- | :--- |
| 編排主軸 | 三天 / 三 Part（Prompting → RAG → Agents） | 控制權階梯 8 模組（不可控 → 收斂 → 校準） |
| 核心隱喻 | 「生成式 AI 是機率軟體，要評估驅動」 | 「把不可控 LLM 逐層收斂成可驗收系統」 |

## 二、控制權階梯總圖

```
M1 不可控性          ← 認識問題：取樣、推理、多模態都是機率輸出
M2 意圖收斂  prompt→spec   ← CTCO、few-shot(對齊)、chaining、spec 契約（高潮）
M3 結構收斂  schema        ← JSON mode → function calling → Structured Outputs
M4 知識收斂  RAG           ← embedding → vanilla RAG → vector DB → advanced → agentic
M5 行為收斂  agent         ← function-calling agent、guardrails、injection、Responses 內建工具
M6 協作收斂  multi-agent   ← Agents SDK handoff、deep search、跨模型互審
M7 校準層    eval          ← RAG 評估、feedback loop、合成資料微調
M8 整合      capstone      ← 串 M1–M7 的可控問答助理
```

每一層的本質：**把「下一步由誰決定」的控制權，從模型手裡逐格收回到系統手裡。**

## 五、ihower 有、本課可補強的缺口（撰寫講義時的加值點）

這些 ihower 教材有教、但現有 notebook 著墨較少，建議在講義補上理論段落：

1. **M1**：Tokenizer 原理、context window 經濟學、Model Spec／指揮鏈的官方定位（ihower 1-1, 3-2）
2. **M2**：自回歸前向性 → 為何「給思考時間」有效的原理（ihower 1-3 補充頁）
3. **M4**：Hybrid Search、Contextual Embeddings、GraphRAG 路線、Long-context RAG 的取捨辯論（ihower 2-4）；RAG Precision/Recall 為何 Recall 實務難算
4. **M5/M6**：MCP（原理/server/client/Registry roadmap）、Computer Use、CodeAgent、The Bitter Lesson、「何時才該用 agent」的兩個硬需求（ihower 3-3）
5. **M7**：5-Level 評估成熟度的完整敘事、gpt-prompt-engineer / DSPy / TextGrad 自動最佳化（ihower 1-5）
6. **收尾觀點**：「準確率多高才能上 production」、AI 複合系統設計、新時代 AI Engineer 技能差異（ihower 結語）
